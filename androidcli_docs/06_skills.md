# Skills Management

Manage specialized agent skills for Android development.

## Commands

### List Available Skills
```bash
android skills list
```

### Find Skills
```bash
android skills find <keyword>
```

### Install Skill
```bash
android skills add <skill-name>
```

### Remove Skill
```bash
android skills remove <skill-name>
```

## Available Skills Categories

- **UI/UX**: Navigation, Material Design, Edge-to-edge
- **Performance**: Perfetto trace analysis
- **Testing**: Testing setup, Compose testing
- **Migration**: XML to Compose migration, AGP upgrade
- **Wear OS**: Wear Compose Material 3
- **Security**: Intent security
- **Billing**: Play Billing Library

## Example

```bash
# Find navigation-related skills
android skills find navigation

# Install a skill
android skills add navigation-3
```
