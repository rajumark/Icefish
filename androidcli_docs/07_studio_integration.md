# Android Studio Integration

Commands to interact with Android Studio IDE.

## Commands

### Find Declaration
```bash
android studio find-declaration
```
Navigate to the declaration of a symbol.

### Find Usages
```bash
android studio find-usages
```
Find all usages of a symbol.

### Open File
```bash
android studio open-file <file-path>
```
Open a file in Android Studio.

### Check Studio Status
```bash
android studio check
```
Check if Android Studio is running.

### Analyze File
```bash
android studio analyze-file <file-path>
```
Analyze a file for issues.

### Render Compose Preview
```bash
android studio render-compose-preview
```
Render a Compose preview in Android Studio.

### Version Lookup
```bash
android studio version-lookup
```
Look up latest versions of Maven artifacts, Android versions, etc.
